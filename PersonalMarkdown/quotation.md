## Deliverables

1. **Discovery & Strategy** — Brand positioning, content architecture, competitor analysis
2. **UI/UX Design** — Wireframes, visual design, design system/token architecture, responsive layouts (mobile-first)
3. **Custom Animations** — Scroll-reveal, parallax, 3D cover flip with spring physics, blob morph, infinite marquee — all hand-coded (no external libraries)
4. **Frontend Development** — Astro components, scoped CSS, accessibility (WCAG 2.1 AA), reduced-motion support, no-JS fallback
5. **Backend / API** — Contact form endpoint, Resend email integration, input validation, error handling
6. **SEO & Meta** — Open Graph, Twitter Cards, canonical URLs, semantic HTML, favicon set
7. **Performance & Optimisation** — Astro Image pipeline, lazy loading, < 3KB JS budget, CLS prevention
8. **Deployment & DevOps** — Cloudflare/Vercel setup, environment config, DNS, SSL, CI/CD build pipeline
9. **QA & Testing** — Cross-browser testing, device testing, accessibility audit, form testing
10. **Content Population** — Copywriting integration, image sourcing/editing, case study entries
