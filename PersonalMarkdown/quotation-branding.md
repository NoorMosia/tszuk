## Deliverables Breakdown

### Phase 1: Discovery & Strategy

| Deliverable | Description |
|-------------|-------------|
| Brand Discovery Workshop | 2–3 sessions with the client to understand their vision, audience, values, and market position |
| Competitor & Market Analysis | Research into the competitive landscape, identifying whitespace and positioning opportunities |
| Brand Positioning Statement | A clear articulation of who the brand is, who it serves, and why it matters |
| Audience Personas | 2–3 target audience profiles to guide all creative decisions |
| Creative Brief | A consolidated document guiding all subsequent design and development work |

### Phase 2: Brand Identity

| Deliverable | Description |
|-------------|-------------|
| Logo Design | Primary logo, secondary/alternate marks, icon/favicon variations (3 concept directions, 2 revision rounds) |
| Colour Palette | Primary, secondary, and accent colours with usage guidelines |
| Typography System | Font selection, hierarchy, and pairing (headings, body, accent) |
| Visual Language | Graphic elements, patterns, textures, photography direction |
| Brand Slogan / Tagline | Crafted messaging — a concise line that captures the brand's essence |
| Tone of Voice | Guidelines for how the brand speaks across all touchpoints |
| Brand Guidelines Document | A comprehensive PDF covering logo usage, colour specs, typography rules, do's and don'ts, tone of voice |

### Phase 3: Website Design & Development

| Deliverable | Description |
|-------------|-------------|
| Wireframes & Layout | Information architecture, content flow, responsive wireframes |
| Visual Design | Full-fidelity mockups applying the brand identity to the web |
| Design System / Tokens | CSS custom properties for colours, spacing, typography, motion |
| Frontend Development | Astro components, scoped CSS, semantic HTML, accessibility compliance |
| Custom Animations | Hand-coded scroll-reveal, parallax, 3D cover flip, blob morph, marquee (no external libraries, < 3KB JS) |
| Contact Form & API | Server-side form processing with Resend email integration |
| SEO & Meta | Open Graph, Twitter Cards, canonical URLs, structured markup |
| Performance Optimisation | Image pipeline, lazy loading, CLS prevention |
| Deployment | Cloudflare/Vercel setup, DNS, SSL, environment config |
| QA & Testing | Cross-browser, device, accessibility audit, form testing |

### Phase 4: Handover & Launch

| Deliverable | Description |
|-------------|-------------|
| Brand Asset Package | All logo files (SVG, PNG, PDF), colour swatches, font files |
| Brand Guidelines (PDF) | Print-ready document for internal use and external partners |
| Source Code | Full website codebase with documentation |
| Launch Support | Go-live assistance, DNS cutover, monitoring |
| Post-Launch Support | 30 days bug fixes included |
